# Shared Kiln artwork

The owner explicitly selected the entire `kiln_upscale.png` image for the online Shared Kiln on 2026-09-19. `shared_kiln_owner_reference.png` is an unchanged copy of that supplied image, adopted here as an approved visual asset.

Its Low / Middle / High layout and 2 / 2 / 3 printed slots match V1.2.7. The application still derives ceramic placement, player-count locks, heat, and localized accessible labels from live game state. Chinese labels are rendered over the printed English headings.

The image's original directory was `v1.2.3`; this approval is for its artwork, not that historical ruleset.
