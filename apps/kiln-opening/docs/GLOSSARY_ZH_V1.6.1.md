## 1. 文风规范 Style guide

### 1.1 语体

- **宋时窑坊口吻，现代桌游清晰度。** 名称取宋代匠作、窑务、市井与官署用语（坯、釉、匣钵、
  覆烧、火照、牙行、漕运、州衙、御窑、贡瓷），规则句子用简洁的现代书面语，可略带文言节奏
  （“每轮一次”“定品后”“付1柴”），但不用生僻字、不用整句文言，不用明清器物或制度名（如博古架、多宝格）。
  规则书正文采用业主2026-10-16修订的平实口吻：用“把”“在”“要／必须”“不能”“才可以”“空着”“装进”“放进”，
  不用“将”“于”“须”（强制效果除外）“不得／不可”“方可”“空置”“装入”。牌面短提示仍可用紧凑写法。
- **名词短，动词实。** 地点、技艺、阶段名以 2–4 字为宜；动作用单音或双音动词：派工、制坯、
  饰纹、施釉、装窑、承接、完成（委托）、交付、习得、翻、亮、弃、收。
- **机制先于意境。** 每个数字、费用、时机、条件、上限都必须保留；有歧义时宁可多写半句。
- **可选与强制（R4）：** 技艺与窑口能力除明写“须”者外一律可选；放弃不消耗“每轮一次”。
  - 凡需玩家作选择、付费或可能不利的效果，文字中必写“可”或“你可以”。
  - 强制效果写“须”。V1.6.1 起唯一强制的技艺效果是色样簿“习得时”的承接（只要能承接：看过的牌或委托榜上的委托；规则书变更25）。
    V1.6.2 的色样簿换单本身可选（“可弃”）；一旦换单，就要精选3：承接所看3张之一或榜上1张，其余弃置（R4；规则书变更25，裁定R25）。
  - 纯收益型效果（放弃毫无所得）以陈述句书写，不写“可”：看火、大陶车与饰坯匣的减免、汝窑、官窑、
    贡瓷、清玩斋、色样簿的持续上限、终局陈列与计分。这只是写法；规则上它们依 R4 仍属可选。
    数字版自动结算看火已由审计记录，其余是否自动结算由 IMPLEMENTATION_DECISIONS 记录（见第9节）。
  - 不得把“既无‘可’也无‘须’”理解为强制。
- **地点名与动作词分开：** “制坯饰纹”“施釉装窑”作地点名；指在该地点的工人行动时写
  “制坯饰纹行动”“施釉装窑行动”（或“执行施釉装窑的师傅”）。泛指动作时，form 写“制坯”，load 写“装窑”，
  glaze and load 写“为1件坯施釉装窑”（或“为它施釉并装窑”），必须带宾语，以免读作限于该行动
  （业主用词，2026-10-16；“施釉入窑”不再使用）。“入窑”只作器物状态名。
- **量词：** 器物与坯用“件”（1件坯，不写“1坯”）；工人用“名”；委托、技艺牌、窑火牌、控火牌用“张”；
  拥有的技艺用“项”（“至多3项技艺”）；修订4起纹饰不单独计费，减免写“1件坯少付1铜钱”；标记、御令用“个”。

### 1.2 标点与数字

- 使用全角中文标点：，。；：（）「」“”、。并列选项在紧凑文字中用全角斜线“／”。
- 数字一律用半角阿拉伯数字，数字与单位之间**不加空格**：`2泥`、`3铜钱`、`4分`、`1件`、`第3轮`。
- 正负修正用 `+1`、`−1`（U+2212 减号，与英文源一致），范围用短横 `0–5`，张数用 `×`：`−2×1`。
- 计算式用半角 `=` `+`，两侧留空格：`实际火候 = 全窑火候 + 温区修正 + 窑工标`。不用全角“＋”；
  紧凑文字中的“并且”写“并”或“，”。
- 委托要求：单件委托各项以 ` · ` 分隔；多件委托各维度以全角“；”分隔；同一维度内的并列器型
  用 ` + `（指定器型组合）或“、……或”（任选其一）。
- 品质高低在界面图例中一律按 `臻品 > 上品 > 良品 > 瑕品` 排列显示。

### 1.3 费用、分数与御令的写法

| 内容 | 紧凑写法（牌面／按钮） | 完整写法（规则正文） |
| --- | --- | --- |
| 费用 | `付2铜钱`、`付1泥1柴` | `支付2铜钱`、`支付1泥和1铜钱` |
| 获得资源 | `得1泥1柴` | `获得1泥和1柴` |
| 胜利分 VP | `+4分`、`4分` | `获得4分`（中文正文不写“VP”，统一用“分”） |
| 御令 Crown | 图标 `👑`，数量写 `👑×2` | `2个御令`；“印有至少1个御令的委托” |
| 品质门槛 | `上品以上` | `上品或臻品` |
| 减免 | `少付1铜钱`、`泥总费−2，最低为0` | `少付1铜钱`、`泥总费减2，最低为0` |

### 1.4 时机用语（固定写法）

`每轮一次，〈时机〉：〈效果〉`；无特定时机时写 `每轮一次：〈效果〉`。

烧窑阶段烧成。御窑器物不使你成为控火者，但对你的技艺与窑口能力而言，算作本次烧成中的器物

窑位签只用于共窑。

与色样簿的换单同在“工人行动之前或之后”时，二者先后由你自定（V1.6.2）。

## 8. 技艺通则（Tech Clarifications 中文版）

逐字取自 [V1.6.2 中文规则书](./KILN_OPENING_v1.6.2_ZH.md)附录B“技艺通则”（修订5后的版本：减免一条只剩师傅与饰坯匣两项，变更40）。

- **练泥、御烧优先**是技艺或令牌效果，不是工人行动。它们不算制坯饰纹行动或施釉装窑行动，也不触发需要这些行动的效果。
- **支烧窑具、覆烧、窑位签**只作用于共窑。御窑只容纳1件，用它自己的御窑修正。
- **窑工：**窑工标在装窑时选定，与御窑修正的选法相同，且是公开信息。钧窑的调整叠加在它之上；复烧重算时，窑工标留在原处。
- **火照**在基础火候确定后、翻窑火前结算。置底的牌留在牌堆底；若窑火牌堆用尽，把弃牌堆洗混后放在它上面，所以置底的牌最后才翻出。你可以谈论看到的内容，但不能把牌给别人看。
- **色样簿：**它的精选是技艺效果，不算瓷牙行行动；由此承接的榜上委托照常在你的回合结束后补上。拥有此牌期间，每次收工的上限都是5张。换单时弃置的主委托放入主委托弃牌堆，起始委托放回盒中。
- **匣钵护烧**与**复烧**只作用于你本次烧成中（共窑或御窑）符合条件的器物，不作用于先前各轮烧成的器物；复烧额外翻出的窑火牌不影响任何其他器物。
- **减免：师傅的减免与饰坯匣是两项各自独立的减免，可以作用于同一件坯（其2铜钱可降到0）。大陶车只减泥；定窑的额外坯不是瓶或香炉。**
- **高徒**派往瓷牙行时，该学徒按师傅效果结算：精选3，承接至多2张。
- **哥窑开片**是定品后效果。有匣钵护烧时，本应为瑕品的器物算作良品，可以再开片；匣钵护烧的“良品变上品”与开片可以作用于同一件器物，因为开片不改变上品的品质。

8. **（修订5，已裁定，2026-10-31：R31，原 INT Same-turn delivery）承接当回合交货：**规则书写在手委托“可以作为自由行动在你之后的任何回合或任何一次烧窑之后完成”（中文第419行），
