**2–4人 · 90–120分钟 · 12岁以上** *立作坊，共窑火，精匠艺。* 一款以宋代窑场作坊为题材、中等重度的派工策略游戏。

## 相对v1.2.7的改动

版本号定为v1.6.2（工作名v1.3已被更早的一版草稿占用）。本草稿采纳了全部已定改动，并删去了所有涉及陶车坊、釉饰坊、窑坊、起始技艺、师傅超放规则、窑坊调位、“已施釉未装窑”状态以及旧委托阶段的文字。

1. **坊内地点。**每块窑口板上有两个在你自己作坊里进行的行动：制坯饰纹与施釉装窑，各有2个工位，开局时各只开放1个。坊内行动以动作命名；中央地点以所去之处命名：泥柴场、瓷牙行、陶工行（沿用原名）、漕运码头（原杂作行）与州衙（原朝廷赞助）。
2. **制坯时饰纹，装窑时施釉。**制坯饰纹行动负责制坯与饰纹；施釉装窑行动负责施釉与装窑。不再有“已施釉而未装窑”的状态。
3. **火标。**执行施釉装窑的师傅把该玩家的火标暗置于其1件器物上；基础火候确定后，按起始玩家顺序，把火标翻为+1或−1，或收回。
4. **取消师傅超放。**所有容量都是绝对上限。
5. **不再有起始技艺；至多3项技艺，每门类至多1项；**共18张，每门类6张。坯作技艺添设制坯饰纹的第二工位，釉作技艺添设施釉装窑的第二工位；火作技艺不添设任何工位。
6. **委托。**只能完成在手委托，并按派工阶段的回合顺序进行。榜上委托被承接后，要等承接者的回合结束才补上。师傅的一次承接可以改为看三取一；色样簿改为提高委托上限的技艺。
7. **御烧优先**改为为1件坯施釉并装窑。**御窑**由御匠代烧：2 + 窑火修正 + 装窑时选定的修正，不受控火影响。
8. **州衙（原朝廷赞助）**改为有容量限制的地点，工位数1／1／2（2人／3人／4人），声望0–2时可用；师傅付3铜钱。御赐改为1泥、1柴和1铜钱（取消了3铜钱的选项），因此花钱买第1格是实实在在的开销，而不是原数返还。
9. **共窑**每名玩家2个窑位：4个（2-1-1）、6个（2-2-2）、8个（3-3-2）。
10. **哥窑**重做：开片纹饰由画花取代；哥窑改为每轮定品后令1件良品开片（品质变为上品，并保留开片标，完成委托时可作任意一种纹饰）。
11. **火照**改在基础火候确定后、翻火标前结算（附录B）。
12. **窑火牌堆：**弃牌堆为公开信息；只有牌堆用尽时才重洗。
13. **委托分值：**O16为9分，O21为9分，O31为12分，O32为15分，O33为14分，O40为15分。
14. **纹饰一律2铜钱**（素面原为1铜钱）。师傅的制坯饰纹加成改为**制2件时1项纹饰少付1铜钱**（原为泥总费−1）。饰坯匣改为少付1铜钱，而非减至0。定窑额外坯的费用为1泥和1铜钱。S10改为4分。
15. **窑骰。**每轮开工时，掷一枚点数为1、1、2、2、3、3的骰子，结果就是本轮基础火候的起点（原来固定为2）。控火、0–5的限定、窑火牌以及其后的一切都不变。御匠代烧的御窑同样以此点数取代原来的2。
16. **参与控火**必须在共窑中有器物。由于御窑不受控火影响，其主人不能再仅凭御窑中的器物参与共窑的控火（堵住第7条带来的“无代价捣乱”漏洞）。
17. **为“只能完成在手委托”留出余量。**每人开局持2张起始委托和1张主委托（原为1张加1张），委托上限为4张（有色样簿则为5张；原为3／4张）。承接张数不变，仍为学徒1张、师傅2张。
18. **声望轨仍是可选路线。**声望轨上不派工人。州衙（原朝廷赞助）自声望0起开放（取消声望1的门槛），御赐为1泥、1柴和1铜钱；两者合起来，用更少的文字解决了第1格的返还问题，也让铜钱充裕的玩家可以花钱登上声望轨，作为铜钱的去处。御烧优先保持草案原样；O17–O20保持牌面原样。
19. **画花取代开片**成为第4种纹饰（2铜钱）。开片如今只由哥窑在窑中产生，以开片标表示。改字的卡牌：S13、O13、O17、O23、O39、O40、O46；饰坯匣的文字改为刻花、印花或画花。
20. **技艺分数在习得时计入。**每项技艺的1分在拿取技艺牌的那一刻记录，而不是在终局结算。这只是记分方式的改变；技艺不会失去。
21. **v1.6.2——瓷牙行与中央地点的师傅效果。**瓷牙行不再给资源。学徒查看主委托牌堆顶2张，从委托榜或这2张中承接1张；师傅查看牌堆顶3张，从委托榜和这3张中承接至多2张；翻看而没有承接的牌放到牌堆底（取消盲接）。泥柴场师傅获得6份资源（取消付1铜钱的选项）。陶工行师傅可按牌面价习得至多2项不同门类的技艺（不再减免）；技艺的补牌改在拿牌者回合结束后进行，与委托榜相同。漕运码头师傅获得4铜钱，并不看牌面拿取主委托牌堆顶1张。
22. **v1.6.2——技艺复核。**色样簿增加每轮一次的换单（弃1张在手委托，看牌堆顶3张，承接1张）。漕船改为每轮一次，完成委托时得2铜钱；原来的派工阶段完成委托，相比交货阶段完成并无实际收益。匣钵护烧：你的器物永不为瑕品，且每轮一次1件良品变上品；费用3。柴簿：压火与添柴不付柴；费用2。复烧翻2张取1张。高徒与看火费用改为3；火照维持3，因为置底的窑火牌改变的是所有玩家的烧成，而不只是拥有者的。
23. **v1.6.2——起始委托由16张减为8张，分值拉平。**4张釉委托（白釉、青釉、灰青釉3分+4铜钱；月白釉4分+4铜钱），小器型任选3分+4铜钱，瓶或香炉3分+5铜钱，刻花／印花／画花3分+3铜钱，任意2分+4铜钱。旧牌堆中指定器型只给2分、指定纹饰却给4分，而在纹饰一律2铜钱之后两者都是无代价的选择，开局发牌可相差4–5分。准备流程不变：每人2张起始委托+1张主委托。
24. **v1.6.2——主委托复核与牌堆流转。**纹饰要求不再额外加分（纹饰一律2铜钱）：O05改为6分+3铜钱，O19与O20改为6分，O38改为12分，O39改为13分。只限器型的单件委托升为4分（O01–O03）；任选器型的单件委托调为O14 5分+3铜钱、O15 5分+4铜钱；O04改为7分+3铜钱；O22改为9分。上品两件委托补上原本缺少的配合溢价：O26 11分、O27 12分、O28 11分、O30 13分；臻品两件委托O32 16分、O33与O34 15分+5铜钱。翻看而未承接的牌（瓷牙行、色样簿）改为放到主委托牌堆底，而非弃牌堆，这样4人局也无需重洗。
25. **关键词：精选N。**查看主委托牌堆顶N张，承接其中1张或榜上1张，其余放到牌堆底。瓷牙行：学徒精选2，师傅精选3并承接至多2张；色样簿：习得时精选3，每轮一次的换单也是精选3。仅为措辞调整。
26. **柴簿改为控火牌。**柴是公开信息，压在暗牌下的柴不可能保密。原来的暗附加柴改为随技艺牌附带的2张控火牌：**柴簿压火**（1柴，−2）与**柴簿添柴**（1柴，+2）。拥有者从5张中暗选、打出1张；普通的压火与添柴仍免柴。选项与价格与原来相同。控火牌增至14张，牌背相同，暗牌不泄露任何信息。
27. **取消技艺分。**习得技艺不再得1分。技艺复核之后，每张技艺牌凭效果本身就值回票价（第一张：添设工位；第二张：火作技艺效果约4.7分），这1分实际上只在补贴第三张技艺和第4轮以后的购买。技艺是作坊成长，委托与御令才是分数。清玩斋的终局分保留。牌面价格不变；测试时关注每人技艺数与第4–5轮的陶工行派工。

## 游戏概述

在《开窑》中，每位玩家主持一座窑场作坊，取法宋代五大名窑传承之一。你的师傅与学徒采集泥柴、制坯饰纹、在入窑时施釉，争接委托、研习技艺，并与其他作坊共用一座窑——这座窑最终烧成什么，受每一座参与作坊的影响。

**派工决定你的作坊备下什么；共窑的烧成决定这些东西最终成为什么。**本次烧成中的所有器物共用同一个基础火候和同一张窑火牌，所以你烧出什么，有一部分取决于其他人决定怎么烧火。

游戏固定进行**5轮**。

## 术语

| 术语 | 含义 |
| --- | --- |
| 器物 | 一张器型卡，依次经历坯、入窑、成器、已交付四个状态。 |
| 学徒 | 普通工人。放到某地点后，获得该地点的学徒效果。 |
| 师傅 | 每位玩家独有的师傅工人。放到某地点后，获得该地点的师傅效果；派工规则与学徒相同。 |
| 中央地点 | 位于中央行动板上、所有玩家共用的地点：泥柴场、瓷牙行、陶工行、漕运码头、州衙。 |
| 坊内地点 | 位于你自己窑口板上的地点：制坯饰纹与施釉装窑。各有2个工位，其中1个要习得相应技艺后才添设。 |
| 技艺 | 在陶工行习得的永久性作坊技艺。每人至多3项，每门类至多1项。习得坯作技艺即添设你的制坯饰纹第二工位；习得釉作技艺即添设施釉装窑第二工位；火作技艺不添设工位。 |
| 技艺效果 | 印在技艺牌上的效果。技艺效果**不是工人行动**，除非另有明文，否则不会触发需要该工人行动的效果。 |
| 委托 | 印有器物要求与奖励的起始委托卡或主委托卡。只能完成你手中的委托。 |
| 瓷牙行 | 用于承接主委托的中央地点。 |
| 御令委托 | 印有至少1个御令的委托。每个御令使御府声望推进1格，直至声望4；到达声望4之后再获得的御令，每个得1分。 |
| 在手（已承接）委托 | 你手中的委托，其他玩家无法取走。 |
| 精选N | 查看主委托牌堆顶N张。承接其中1张，或承接委托榜上的1张主委托；这N张中其余的放到牌堆底。 |
| 御窑 | 御府声望达到2时获得的私人单件窑板块。其中的器物不受控火影响：实际火候 = 窑骰点数 + 窑火修正 + 装窑时选定的御窑修正（−1、0或+1）+ 火标（如有）。 |
| 御烧优先 | 御府声望达到3时获得的每局一次令牌。在你的工人行动之前或之后，交出此标，可以为你的1件坯施釉并装进你空着的御窑。 |
| 火标 | 玩家的标记，一面是+1，一面是−1。执行施釉装窑的师傅把它暗置于该玩家的1件入窑器物上；基础火候确定后，把它翻为+1或−1，或收回。其数值计入该器物的实际火候。 |
| 适烧火候 | 各种釉所需要的火候：白釉1、青釉2、灰青釉3、月白釉4。 |
| 基础火候 | 以本轮窑骰点数（1、2或3）为起点，加上所有控火修正，再限定在0–5之间。整次烧成共用。 |
| 全窑火候 | 基础火候加上窑火修正。不设上下限。 |
| 实际火候 | 共窑器物：全窑火候 + 温区修正（印在窑位上，或由支烧窑具选定）+ 火标，再计入适用的能力。御窑器物：窑骰点数 + 窑火修正 + 选定的御窑修正 + 火标。 |
| 火候差 | 实际火候与适烧火候之差的绝对值，决定品质。 |
| 装窑 | 为1件坯施釉，然后放进共窑中一个空的启用窑位，或你空着的御窑。 |

## 游戏准备

1. 把中央行动板与共窑板放在桌子中央。共窑板：**4人局**使用全部8个窑位（高温区3个、中温区3个、低温区2个）；**3人局**使用6个窑位，盖住1个高温区与1个中温区窑位（2-2-2）；**2人局**使用4个窑位，盖住1个高温区、2个中温区与1个低温区窑位（2-1-1）。2人局与3人局还要盖住州衙的第二工位。
2. 分别洗混**8张起始委托**与**48张主委托**。发给每位玩家**2张起始委托和1张主委托**，这3张就是该玩家的起始手牌，**必须保密**。
3. 把没有发出的起始委托（如有）放回盒中。把剩余的主委托重新洗混，然后从左到右翻开**6张主委托**，正面朝上排成委托榜。
4. 把18张技艺牌按坯作、釉作、火作分成3叠，每叠6张。各叠分别洗混，每个门类翻开**2张**，正面朝上。把2张柴簿控火牌放在火作叠旁，谁习得柴簿就归谁。
5. 洗混12张窑火牌，面朝下放成牌堆，旁边留出正面朝上的弃牌堆位置。把窑骰放在基础火候轨旁。
6. 把泥、柴、铜钱与器型卡放在大家都方便取用的地方。器型卡按器型分开摆放。
7. 把**4块御窑板块**放在御府声望轨旁。
8. 每位玩家选择一种颜色，拿取该颜色的1名师傅、3名学徒、1个火标、1个声望标、2个第二工位盖片，以及压火、守火、添柴各1张。把该颜色的**御烧优先标**放在声望轨第**3**格。
9. 随机决定起始玩家。按回合顺序的逆序，每位玩家选择1块尚未被选走的窑口板，并用第二工位盖片盖住其制坯饰纹与施釉装窑的第二工位。
10. 每位玩家把**1名师傅 + 3名学徒**放在面前，作为可派工人。
11. 每位玩家的御窑区暂时空着，直到通过御府声望获得御窑。
12. 每位玩家获得**2泥、2柴和3铜钱**。
13. 把所有声望标放在声望轨第**0**格，轮次标放在第**1**轮。

## 每轮流程

| 阶段 | 名称 | 概要 |
| --- | --- | --- |
| 1 | 开工 | 掷窑骰，定出本轮基础火候的起点；轮换委托榜；补齐各公开区；重置“每轮一次”的能力。 |
| 2 | 派工阶段 | 轮流派工到中央地点与坊内地点。 |
| 3 | 烧窑阶段 | 控火 → 基础火候 → 火照 → 翻火标 → 翻窑火 → 实际火候 → 定品。 |
| 4 | 交货阶段 | 按回合顺序，逐张完成在手委托。 |
| 5 | 收工 | 收回工人与标记；削减手中委托；传递起始玩家标。 |

## 第1阶段——开工

每轮一开始，先**掷窑骰**，把基础火候标放到掷出的点数上（1、2或3）。本轮的基础火候就从这里起算，之后再由控火调整。然后，在第2–5轮：

1. 把委托榜**最左边的2张**主委托弃入主委托弃牌堆。
2. 把余下的**4张主委托**向左推。
3. 翻开**2张新的主委托**，从左到右填入空位，使委托榜恢复为**6张**。

接着重置所有标明**每轮一次**的能力，然后由起始玩家开始派工阶段。

## 第2阶段——派工阶段

从起始玩家开始，按顺时针方向，每位玩家轮到时必须把**1名可派工人**放到一个合法工位上，并立即结算其行动。如此轮流，直到**每位玩家的工人全部派出**，然后进入烧窑阶段。

每位玩家每轮可派**1名师傅和3名学徒**。每名工人每轮只派出一次，因此每位玩家全局共派工**20次，其中师傅5次**。

- 工人可以放到某地点任意一个**空着的**工位上；该地点其他工位上已有的工人，无论是你的还是别人的，都不影响。**容量是绝对的：**某地点的工位全部被占满后，任何工人（包括师傅）都不能再派往该地点。
- 师傅遵守与学徒相同的派工规则，并获得所在地点的师傅效果。
- 只有当你能执行该地点**至少1次主行动**时，才可以把工人派到那里。“至多2”的意思是**1或2，不能是0**。可选的额外收益仍然可以放弃。
- **派工阶段不能跳过。**漕运码头没有容量限制，也不需要资源，所以可派工人总是可以派往那里。
- **坊内地点**在你自己的窑口板上。每个坊内工位每轮只能使用**一次**。尚未添设的工位不能使用。

### 泥柴场

| 工人 | 效果 |
| --- | --- |
| 学徒 | 获得**3份资源**，泥和柴任意搭配。 |
| **师傅** | 获得**6份资源**，泥和柴任意搭配。 |

### 制坯饰纹（坊内）

| 工人 | 效果 |
| --- | --- |
| 学徒 | 制**1件坯**：支付其泥费，选择1种纹饰并支付纹饰费。 |
| **师傅** | 制**至多2件坯**，每件各选1种纹饰并付费。**若制2件，其中1项纹饰少付1铜钱。** |

- 只有当你至少能为1件坯付清泥费和纹饰费时，才可以派工到这里。
- 制成的器物就是**坯**：它记录器型与纹饰，留在你的作坊里等待装窑。

### 施釉装窑（坊内）

| 工人 | 效果 |
| --- | --- |
| 学徒 | 选择你的**1件**坯，为它选定釉并装窑。 |
| **师傅** | 为你的**至多2件**坯施釉并装窑。然后把你的**火标暗置**于你在共窑或御窑中的1件器物上。师傅留在施釉装窑工位上。 |

- **装窑**就是把坯放进共窑中一个空的启用窑位。如果你已经获得御窑且御窑空着，**本次行动装窑的器物中可以有1件**改放进御窑。
- 只有当你至少有1件坯，并且有空的启用窑位或自己空着的御窑时，才可以派工到这里。
- 被盖住的窑位既不算空位，也不能使用。御窑每次烧成只容纳1件。
- 火标在烧窑阶段结算。每件器物上至多只能有1个火标。

### 瓷牙行

**精选N：**查看主委托牌堆顶N张，然后承接其中1张或委托榜上的1张主委托；这N张中其余的放到牌堆底。承接就是把委托收入手中。承接**榜上的**委托时，**它的榜位空着，直到你的回合结束**；然后把它右边的委托都向左推一位，再翻开主委托填入最右边的空位，使委托榜恢复为6张。

| 工人 | 效果 |
| --- | --- |
| 学徒 | **精选2。** |
| **师傅** | **精选3**，但承接**至多2张**而非1张，可在这3张与委托榜中任意搭配。 |

- 师傅至少要承接1张。你的回合结束前委托榜不会补牌，所以师傅的两次承接都只能从此刻榜上的委托中选。
- 一轮之中没有委托上限。收工时，自选弃置委托，直到手中不超过**4**张（有色样簿则为5张）。起始委托与承接的主委托都计入。
- **手中的委托保密。**各人手中的委托张数公开。

### 陶工行

| 工人 | 效果 |
| --- | --- |
| 学徒 | 支付牌面的铜钱费用，习得**1张公开的技艺**。 |
| **师傅** | 选择1个门类，查看该门类牌堆顶的2张**（不足2张则看余下的）**。然后从公开技艺与所看技艺中习得**至多2项不同门类的技艺**，各按牌面价付费。没有拿的所看技艺放回该牌堆底。 |

- 被拿走的技艺的位置**空着，直到你的回合结束**；然后尽可能把各门类补回2张。师傅的第2项技艺只能从此刻摆出的技艺中选。
- 每人至多**3项技艺，每门类至多1项**。
- **添设工位。**习得坯作技艺时，移去制坯饰纹第二工位上的盖片；习得釉作技艺时，移去施釉装窑第二工位上的盖片；火作技艺不添设工位。新添设的工位本轮稍后就可以使用。
- 派工到这里的前提是：你付得起1张公开技艺，且你还没有该门类的技艺。
- 新习得的技艺只要时机允许，本轮就可以使用。**“习得时”**的效果立即结算。

### 漕运码头

| 工人 | 效果 |
| --- | --- |
| 学徒 | 获得**2铜钱**。 |
| **师傅** | 获得**4铜钱**，并不看牌面拿取主委托牌堆顶的1张收入手中。 |

### 州衙

州衙在2人局与3人局中有**1个工位**，4人局中有**2个工位**；御府声望为0、**1或2**时可以使用。与其他地点一样，只要两个工位都空着，同一玩家一轮内可以都使用。

| 工人 | 效果 |
| --- | --- |
| 学徒 | 支付**4铜钱**，御府声望推进**1格**。 |
| 师傅 | 支付3铜钱，御府声望推进1格。 |

- 州衙**不要求御令**：可以由**0→1、1→2或2→3**。所到格的奖励照常结算。
- 州衙**不能把你推进到声望4**，所以声望为3或4时不能使用。

## 第3阶段——烧窑阶段

如果共窑和所有御窑里都没有器物，**跳过烧窑阶段，也不翻窑火牌**。

| 步骤 | 内容 | 得出 |
| --- | --- | --- |
| 1. 控火 | 参与控火的玩家各自暗选1张自己的控火牌，然后同时亮牌并支付柴。从窑骰点数起算，最终结果限定在0–5。 | **基础火候** |
| 2. 火照 | 按起始玩家顺序，拥有火照的玩家可以查看窑火牌堆顶1张，并可以把它置于牌堆底。 | — |
| 3. 翻火标 | 按起始玩家顺序，在器物上暗置了火标的玩家把它翻为+1或−1，或收回。窑工在此时放置窑工标。 | — |
| 4. 翻窑火 | 翻开窑火牌堆顶1张，加上它的修正。 | **全窑火候** |
| 5. 窑位 | 共窑器物：全窑火候 + 温区修正（高温区+1／中温区0／低温区−1，或支烧窑具修正）+ 火标。御窑器物：窑骰点数 + 窑火修正 + 装窑时选定的御窑修正 + 火标。 | **实际火候** |
| 6. 比对 | 结算适用的能力后，比对实际火候与适烧火候。 | **品质** |

- **基础火候与全窑火候属于整次烧成；实际火候属于每一件器物。**
- 基础火候限定在0–5。全窑火候与实际火候不设上下限。

### 控火牌

每位玩家都有相同的3张控火牌：

| 控火 | 柴 | 火候 |
| --- | --- | --- |
| 压火 | 1 | −1 |
| 守火 | 0 | 0 |
| 添柴 | 1 | +1 |

只有**在共窑中至少有1件器物的玩家才参与控火。御窑中的器物由御匠代烧，玩家不能凭它对共窑的火发表意见**。守火永远付得起。拥有**柴簿**的玩家另有2张控火牌：**柴簿压火**（1柴，−2）与**柴簿添柴**（1柴，+2），而且普通的压火与添柴不付柴；仍然只打出1张。烧成后，所有控火牌各自收回。

**基础火候 = 窑骰点数 + 所有最终控火修正之和，限定在0–5。**以窑骰点数2为例：守火 + 守火 + 守火 → 2；添柴 + 守火 + 守火 → 3；压火 + 守火 + 守火 → 1；添柴 + 压火 + 守火 → 2，两位玩家仍然各付各的柴。窑骰点数为3时：守火 + 守火 + 守火 → 3；压火 + 守火 + 守火 → 2；添柴 + 添柴 + 守火 → 5。

### 火标

- 每位玩家有1个火标，一面+1，一面−1。执行施釉装窑的师傅把它**暗置**于该玩家在共窑或御窑中的1件器物上。
- 基础火候确定后，按起始玩家顺序，每位暗置了火标的玩家把它**翻为+1或−1，或收回**。
- 火标的数值计入该器物的实际火候。它不是温区修正：可以与支烧窑具叠加，复烧重算时火标也留在原处。
- 每件器物至多带1个火标。器物离开窑时，收回火标。

### 品质表

| 火候差 | 品质 | 委托资格 |
| --- | --- | --- |
| 0 | **臻品** | 满足任何最低品质要求。 |
| 1 | **上品** | 满足“上品以上”与“良品以上”。 |
| 2 | **良品** | 只满足“良品以上”。 |
| 3或以上 | **瑕品** | 不能用于完成委托，也不能陈列。 |

本次烧成的所有定品后能力结算完毕后，每位玩家可以弃置**1件本次烧成中仍为瑕品的器物**，获得**2铜钱**。把它的器型卡放回相应器型的供应堆。

### 御窑

首次到达**御府声望2**时，取1块御窑板块放进你的御窑区。

- 御窑**每次烧成只容纳1件**。
- 施釉装窑行动中，该行动装窑的器物可以有1件改放进你空着的御窑，而不放进共窑。御烧优先也可以把器物装进御窑。技艺效果一律不能把器物装进御窑。
- 御窑中的器物**由御匠代烧。装窑时，选定御窑修正−1、0或+1并记录下来。它的实际火候 = 窑骰点数 + 窑火修正 + 御窑修正 + 火标（如有），与控火结果无关；它仍在共同的烧窑阶段烧成**。
- 对你的技艺与能力而言，它算作本次烧成中的器物，但不会让你成为控火的参与者：只有共窑中的器物才算。它不占用共窑窑位。
- 烧成后，其器物照常定品，移入主人的成器区。

到达**御府声望3**时，从声望轨第3格取走你颜色的御烧优先标。**每局一次，在你的工人行动之前或之后，交出此标，为你的1件坯施釉并装进你空着的御窑。**这是令牌效果，不是施釉装窑行动。

## 第4阶段——交货阶段

从**起始玩家**开始，按顺时针方向，每位玩家可以**逐张完成任意数量的在手委托**。只能完成你手中的委托。**委托榜上的主委托不能完成**；它们要在派工阶段到瓷牙行承接。交货阶段中委托榜不变。

完成的步骤见下文**完成委托**。

## 第5阶段——收工

1. 玩家取回所有工人。收回仍留在共窑上的窑位签。
2. 自选弃置手中的委托，直到不超过上限**4**张（有色样簿则为5张）。弃置的起始委托放回盒中；弃置的主委托放入主委托弃牌堆。
3. 若本轮是第5轮，进入终局计分。否则，把起始玩家标顺时针传给下一位玩家，并推进轮次标。

## 器物制作

### 制作步骤

1. 获得泥和柴（泥柴场）。
2. 制1件坯并选定纹饰（制坯饰纹）。
3. 为它施釉，并装进共窑，或（若已有）你的御窑（施釉装窑）。
4. 结算共同的烧窑阶段。
5. 用成器完成1张在手委托，或留到终局陈列。

技艺可以压缩这些步骤。

### 器型与制坯费用

| 器型 | 泥费 | 所含张数 |
| --- | --- | --- |
| 碗 | 1 | 10 |
| 盘 | 1 | 10 |
| 笔洗 | 1 | 10 |
| 瓶 | 2 | 10 |
| 香炉 | 2 | 10 |

器型卡**不是硬性的游戏上限**。若某种器型的10张卡都在使用中，先用合适的代用物代替，等有相应的器型卡空出来再换回。

### 纹饰

制坯时选定并付费。每种纹饰都是2铜钱；师傅的制坯饰纹行动与饰坯匣各能使1项纹饰少付1铜钱。

| 纹饰 | 费用 |
| --- | --- |
| 素面 | 2铜钱 |
| 刻花 | 2铜钱 |
| 印花 | 2铜钱 |
| 画花 | 2铜钱 |

### 釉与适烧火候

装窑时选定。

| 釉 | 适烧火候 | 特点 |
| --- | --- | --- |
| 白釉 | **1** | 火候最低的釉。 |
| 青釉 | **2** | 低温到中温。 |
| 灰青釉 | **3** | 中温到高温。 |
| 月白釉 | **4** | 火候最高的釉；通常需要烧得更旺。 |

选釉，就是在共窑的火势揭晓之前，先为器物定下你想要的烧成结果。

### 器物状态

- **坯：**记录器型与纹饰。留在你的作坊里，可以装窑。
- **入窑：**另外记录釉。放在共窑或你的御窑中，直到烧成。
- **成器：**另外记录品质，并移入你的成器区。
- **已交付：**已用于完成某张委托，不能再用。

## 作坊发展

每位玩家作坊的长期引擎由以下几部分构成：

> **1项窑口传承 + 至多3项技艺（每门类1项）+ 至多2个添设的第二工位**

### 技艺效果与工人行动

**技艺效果不是工人行动。**如果某项技艺让你执行工人行动的一部分，例如制坯、施釉或装窑，这**不**算执行了该工人行动，也不会触发需要该行动的效果，除非技艺文字写明。御烧优先同样是令牌效果。

### 技艺规则

- 坯作、釉作、火作技艺恰好各有6张。
- 每位玩家至多拥有3项技艺，每门类至多1项。
- 习得坯作技艺即添设你的制坯饰纹第二工位；习得釉作技艺即添设施釉装窑第二工位；火作技艺不添设工位。
- 按各技艺牌上印的时机与使用次数结算。

## 委托与御府声望

### 主委托牌堆与委托榜

游戏中只有一个**48张的主委托牌堆**和一个**6张的委托榜**。另有一个单独的8张起始委托牌堆，只在游戏准备时使用。

委托榜从旧到新排列：**最左边的一张最旧**，**最右边的一张最新**。

榜上的主委托只有**在瓷牙行被承接**或**在开工时被弃置**时才会离开委托榜。某张被承接后，它的榜位空着，直到承接者的回合结束；然后把它右边的每张委托向左推一位，再翻开主委托填入最右边的空位，使委托榜恢复为6张。如果一个回合中从榜上拿走了不止一张委托，在该回合结束后再补榜，而不是在两次承接之间补。

委托可以奖励**分数、铜钱与0–3个御令**。商贾委托通常要求较宽松、铜钱较多。御令委托通常要求较具体、铜钱较少，并能推进御府声望。

### 承接委托

在派工阶段到瓷牙行承接主委托：学徒精选2，师傅精选3并承接至多2张。漕运码头的师傅不看牌面拿取牌堆顶1张。习得**色样簿**时，无需瓷牙行行动即可立即精选3，并且你的委托上限升为5张，每轮还可以弃1张在手委托换一次精选3；见附录B。

在手委托：

- 在你**秘密的委托手牌**中，其他玩家无法影响；
- 收工时计入你的委托上限；
- 可以在之后任何一个交货阶段完成；
- 完全按卡面所印计分。

### 完成委托

在交货阶段轮到你时，每完成1张委托：

1. 选择1张在手委托并**亮出**。
2. 选出所需的、尚未交付的成器。
3. 确认器型、釉、纹饰、相互关系与最低品质等全部要求都已满足。
4. 把所用器物压在该委托下面。
5. 记录所印分数。
6. 获得所印铜钱。
7. **逐个**结算御令。每个御令使御府声望推进1格，直到声望4。到达声望4之后，每再获得1个御令，**立即得1分**。途经的每一格奖励都要结算。
8. 把完成的委托正面朝上放进你的计分区。

一件器物只能用于一张委托。

#### 多件委托的要求怎么读

除非卡面**明确写出了特定的配对**，各项要求**彼此独立**。例如委托写着“**碗 + 笔洗；白釉、月白釉各1件；素面、印花各1件**”，你必须恰好使用1件碗和1件笔洗、白釉和月白釉各恰好1件、素面和印花各恰好1件，至于哪件配哪件，由你分配。如果卡面要固定配对，会直接写出来，例如“**碗：白釉 + 素面；笔洗：月白釉 + 印花**”。

### 御府声望轨

御府声望可以通过**已完成委托上的御令**推进，也可以通过**在州衙付费**推进。州衙不能把你推进到声望4。

## 窑口传承能力

窑口板上印的是简短的提示文字；完整效果以本节为准。

### 汝窑 · 天青无瑕

每轮一次，当你完成委托时，若所交付的器物中有1件是**臻品、青釉、素面**，获得**4分**。委托本身不必要求臻品、青釉或素面；只看实际交付器物的属性。

### 官窑 · 内府恩眷

每轮一次，当你完成一张**印有至少1个御令**的委托时，获得**2铜钱和1分**。

### 哥窑 · 金丝铁线

**每轮一次**，定品后，选择你本次烧成中1件此时为**良品**的器物：它开片，品质变为**上品**。在它上面放1个**开片标**，此标一直留在该器物上。

完成委托时，你的每件**开片器都可以视为具有任意一种纹饰**，以满足该委托的纹饰要求；它原本的纹饰不变。开片器永远不是臻品，因此不能满足臻品要求。

### 定窑 · 范制成器

每轮一次，结算制坯饰纹行动时，在你制成1件**碗、盘或笔洗**之后，可以支付**1泥和1铜钱**，再制**1件同器型的坯**并为它饰纹。这件坯的纹饰任选，费用就是这1铜钱。它不计入该行动的制坯件数上限，也不算师傅纹饰减免所说的“2件”之一；对于提到“该行动所制坯”的效果，它算作该行动所制。

### 钧窑 · 窑变天成

每轮一次，实际火候算出后、定品前，你可以支付**1柴**，把你1件器物的实际火候调整**+1或−1**。

### 能力时机

- 多名玩家在同一时机结算能力时，从起始玩家开始，按顺时针顺序依次结算。
- 钧窑在实际火候算出后（已计入火标）、定品前结算。
- 哥窑开片是定品后效果；哥窑玩家自行决定它在己方各项定品后效果中的先后。
- 汝窑与官窑在交货阶段完成委托时触发；开片器的任意纹饰在完成委托时声明。
- 定窑在其制坯饰纹行动中触发。

## 终局与计分

第5轮收工后游戏结束。计分如下：

1. 游戏中记录的全部分数：委托、窑口传承能力、**御前召见**，以及到达声望4后御令所得的分数；
2. 终局陈列；
3. **剩余铜钱每3枚1分**，至多**5分**。

分数最高的玩家获胜。

**平局判定：**①御府声望更高；②已完成委托上印的御令总数更多；③已交付或陈列的臻品更多；④仍然平局，则共享胜利。

## 通则

- **资源无限：**泥、柴与铜钱的公共供应没有上限。若配件用完，使用合适的代用物（如备用标记或筹码），或在纸上记录多出的数量。每种代用物代表的资源种类与数量必须让所有玩家一目了然。
- 泥、柴与铜钱从公共供应中获得；花费的泥、柴与铜钱全部退回公共供应。
- **资源是公开信息。**每位玩家的泥、柴与铜钱总数必须让所有玩家看得清楚，被问到时也必须如实回答。控火选择在亮牌前保密；柴在亮牌时才支付，事先不必押下。
- **不能交易：**玩家之间不能交易泥、柴、铜钱、委托、技艺或器物。
- **协商：**玩家可以讨论各自打算怎么控火、怎么翻火标，也可以做出承诺，但这些承诺没有约束力。玩家必须如实披露公开信息，且不能在玩家之间转移资源或任何游戏配件。
- **手中的委托是秘密信息。**每位玩家手中的委托张数公开。
- **所有未交付的器物都是公开信息**，包括坯、入窑器物与成器，以及它们记录的全部属性。
- 坯、入窑器物与成器跨轮保留，并保持记录的全部属性，直到有规则明确改变、交付或弃置它们。
- 未完成的委托与未使用的器物在终局不扣分。
- 需要抽牌时若主委托牌堆已空，把它的弃牌堆洗混，组成新的牌堆。
- **窑火弃牌堆是公开信息。**游戏中不重洗窑火牌堆；只有在需要翻牌而牌堆已空时，才把弃牌堆洗混组成新牌堆。
- 若某个门类的公开技艺补不到2张，就留空。

### 技艺通则

- **练泥、御烧优先**是技艺或令牌效果，不是工人行动。它们不算制坯饰纹行动或施釉装窑行动，也不触发需要这些行动的效果。
- **支烧窑具、覆烧、窑位签**只作用于共窑。御窑只容纳1件，用它自己的御窑修正。
- **火标：**每件器物至多带1个火标；窑工标与你自己的火标不能放在同一件器物上。钧窑的调整叠加在二者之上。复烧重算时，火标留在原处。
- **火照**按起始玩家顺序结算，在任何火标翻定之前。置底的牌留在牌堆底；若窑火牌堆用尽，把弃牌堆洗混后放在它上面，所以置底的牌最后才翻出。你可以谈论看到的内容，但不能把牌给别人看。
- **色样簿：**它的精选是技艺效果，不算瓷牙行行动；由此承接的榜上委托照常在你的回合结束后补上。拥有此牌期间，每次收工的上限都是5张。换单时弃置的主委托放入主委托弃牌堆，起始委托放回盒中。
- **匣钵护烧**与**复烧**只作用于你本次烧成中（共窑或御窑）符合条件的器物，不作用于先前各轮烧成的器物；复烧额外翻出的窑火牌不影响任何其他器物。
- **减免：师傅的纹饰减免、饰坯匣、定窑的1铜钱额外坯是三项各自独立的减免。前两项可以作用于同一项纹饰（刻花可降到0铜钱）；定窑的额外坯两项都不适用。大陶车只减泥；定窑的额外坯不是瓶或香炉。**
- **高徒**派往瓷牙行时，该学徒按师傅效果结算：精选3，承接至多2张。
- **哥窑开片**是定品后效果。有匣钵护烧时，本应为瑕品的器物算作良品，可以再开片；匣钵护烧自身的“良品变上品”与开片不能作用于同一件器物。开片器永远不是臻品，所以不能满足任何臻品要求，包括画花臻品委托。

## 附录D——完整烧窑流程

如果共窑和所有御窑里都没有器物，**跳过本阶段，也不翻窑火牌**。

1. **暗选控火。**在共窑中至少有1件器物的每位玩家，暗选1张自己的控火牌（压火、守火或添柴；有柴簿的还有柴簿压火与柴簿添柴），而且必须付得起它的柴费。
2. **亮牌付柴。**同时亮出所有控火牌，然后支付全部费用。
3. **定基础火候。**以窑骰点数为起点，加上所有最终的控火修正，再限定在0–5。
4. **火照。**按起始玩家顺序，每位拥有火照且在本次烧成中有器物的玩家，可以支付1柴查看窑火牌堆顶1张，并可以把它置于牌堆底。
5. **翻火标。**按起始玩家顺序，每位在器物上暗置了火标的玩家，把它翻为**+1或−1**，或收回。拥有窑工的玩家在此步骤放置窑工标。
6. **翻窑火。**翻开窑火牌堆顶1张，把它的修正加到基础火候上，得出全窑火候。全窑火候不设上下限。
7. **算实际火候。**共窑器物：全窑火候 + 温区修正（或窑具修正）+ 火标。御窑器物：窑骰点数 + 窑火修正 + 装窑时选定的御窑修正 + 火标。
8. **调火。**按起始玩家顺序，结算钧窑以及其他在实际火候算出后、定品前发动的能力。
9. **定品。**比对最终的实际火候与适烧火候。
10. **定品后结算。**按起始玩家顺序，结算匣钵护烧、复烧、哥窑开片及类似效果。若你在此时机有多项能力，由你决定先后。
11. **折卖瑕品（可选）。**每位玩家可以弃置1件本次烧成中仍为瑕品的器物，获得2铜钱。把它的器型卡放回相应器型的供应堆。
12. **开窑取器。**把其余所有成器移入各自主人的成器区。清空共窑与御窑的所有窑位。火标、窑工标与支烧窑具归还各自的主人，窑火牌正面朝上弃置，控火牌各自收回。

## 附录E——速查

### 一轮流程

1. **开工：**掷窑骰，定出本轮基础火候的起点（1、2或3）；第2–5轮弃置最左边的2张主委托，余下4张向左推，再翻开2张新委托，补回**6张委托榜**；重置“每轮一次”的能力。
2. **派工阶段：**从起始玩家开始顺时针进行；每位玩家每回合必须派1名工人。不能跳过；所有玩家的工人全部派出后结束。
3. **烧窑阶段：**控火 → 基础火候 → 火照 → 翻火标 → 翻窑火 → 实际火候 → 调火 → 定品。
4. **交货阶段：**从起始玩家开始顺时针进行；每位玩家可以逐张完成任意数量的在手委托。榜上的委托不能完成。
5. **收工：**收回工人与标记；把手中委托削减到上限（4张；有色样簿则5张）；若游戏继续，传递起始玩家标并推进轮次。
