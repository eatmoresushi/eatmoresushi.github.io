# V1.6.1 implementation plan

Branch `kiln-opening-next-version`. Authority: [V1.6.1 rulebook](./KILN_OPENING_v1.6.1_EN_SOURCE.md)
and [owner rulings](./RULEBOOK_AUDIT_V1.6.1.md), confirmed 2026-10-14 together with this
plan's UI direction. Engine contract: [ENGINE_V1.6.1_DESIGN.md](./ENGINE_V1.6.1_DESIGN.md).
Chinese terms: [GLOSSARY_ZH_V1.6.1.md](./GLOSSARY_ZH_V1.6.1.md). Phases 1–3 make the rules work; phases 4–6 are the
UI rework. The UI phases follow the `AGENTS.md` rule "avoid visual polish until
a full legal game can be completed".

### Reuse

Much of V1.6.1 comes from V1.2.7, which is in git history:

- **Main Orders:** the V1.6.1 Main deck is the V1.2.7 deck (`b79bb47:data/orders.json`) with six VP changes (O16, O21, O31, O32, O33, O40).
- **Starting Orders:** the 16-card Starting deck is V1.2.6's (`5e21f71`) with changes to S10, S14 and S16.
- **Techs:** about 10 Tech definitions, names and zh text, and their art, already exist (T01, T05, T10–T15, ST01, ST04).
- **Painted:** V1.6.1 keeps Painted, so the Decoration set and the 20 ceramic sprites are unchanged; only the costs change (all 2 Coins). The existing crackle overlay art marks Ge's Crackle ceramics.

  - capacities are absolute;

  - forming with Decoration;

  - Guild & Academy: at most 3 Techs, 1 per discipline;

  - the before/after-action window: Canal Barge, Imperial Priority;
  - Setter's Mark;
  - every Work-timed Tech.
- **Firing**, as explicit timing windows:
  - Kiln Die (seeded, public);
  - Contributions from Shared Kiln owners only, including the no-contributor case;
  - Base Heat clamped to 0–5;
  - Test Pieces (private peek, public bury);
  - Heat-marker step and Kiln Master;
  - Fire card, with an open discard that is reshuffled only when empty;
  - Actual Heat: Shared Kiln and Imperial formulas;
  - Jun → Quality → after-Quality window (Saggars, Second Firing and Ge Crackle) in the owner's chosen order;
  - salvaging a Flawed ceramic for 2 Coins;
  - Inverted Firing stacks.
- **Orders and scoring:**
  - single pass in First Player order;
  - hand limit 4/5 at Cleanup;
  - Crown milestones (fixed Grant);
  - Tribute Ware;
  - Exhibition with +3/+3 diversity bonuses and Connoisseur's Cabinet;
  - 1 VP per Tech;
  - Coins at 1 VP per 3, maximum 5;
  - tie-breakers.
- **Tests:** rewrite the `AGENTS.md` required-tests list for V1.6, add a `test/v16/` suite and retire the V1.4-specific tests.

## Phase 3 — server, privacy, computer player

- **Projection allow-list:** private decisions for the Test Pieces peek, the Commission top-3, Colour Samples and Guild inspection; the Main Order discard is face down; the Fire discard is open.
- **Decision routing:** route each new decision window to the right player.
- **Supabase:** a `v16_rules` migration (allow-list, fingerprint check, RPC gates) and a playtest V1.6 form and migration.
- **Computer player:** rewrite the strategy for V1.6 locations, Techs and firing. Rebuild the fallback so a stalled turn can always leave every phase.
- **Gate:** full games for 2, 3 and 4 players complete in the engine, in the local backend, and against computer players.

## Phase 4 — functional UI rework (DOM)

The V1.6 board geometry makes this rework necessary whatever happens with WebGL.

- **Layout:** replace the transform-scaled 1800px scene with a fluid grid, container queries and a 12px text floor. On phones, use tabs (Table / Kiln / Workshop / Orders) instead of a shrunken board.
- **New components:**
  - `CentralBoard`: 5 locations;
  - `KilnPlayerBoard`: personal spaces with locks, 3 Tech slots, Imperial Kiln, Heat marker;
  - `SharedKiln`: covers by player count, stacks, Setter's Mark, Furniture modifier, markers;
  - a docked, non-modal `FiringStage` with the Appendix D steps and a Heat ladder;
  - Kiln Die readout and open Fire discard.
- **Split `ActionPanel.tsx`** (2,111 lines) into per-location modules that use engine selectors. Remove the rule calculations duplicated in React.
- **Text and styles:** an ID-keyed EN/zh catalogue; design tokens replacing 561 literal colours; layered CSS.
- **Tracked Playwright scenarios:** screenshots across viewports and both languages, plus accessibility checks.
- **Exit:** a full legal V1.6 game in EN and ZH on phone and desktop.

## Phase 5 — motion (DOM/CSS)

- A pure, tested event→animation timeline built from the server event stream. It skips to the end state on reconnect, can be skipped, and respects reduced motion.
- **Animations:**
  - Kiln Die roll that lands on the server's value;
  - simultaneous Contribution flip;
  - Heat-marker and Fire-card flips;
  - worker and ceramic moves;
  - Order shelf: the slot stays empty, then refills.
- **Budget:** a whole firing in 4–5 seconds or less.

## Phase 6 — WebGL kiln and glazes

- **Recommended approach:** a lazily loaded WebGL layer built on the small OGL library (≤ 40 KB gzip chunk), used only for:
  - **glaze baking:** the 100 ceramic appearances, with translucency, glaze pooling in carved and impressed recesses, and highlights, baked once to images that the DOM reuses;
  - **the firing stage:** fire and heat driven by Base Heat and the Fire card, heat haze, per-ceramic heat glow, the glaze-melt reveal when Quality is assigned, crackle growth for Ge, the Second Firing re-glow and the court-fired Imperial Kiln.
- **Rejected:**
  - a full 3D tabletop (three.js / react-three-fiber);
  - a PixiJS canvas board.

  This is a text- and decision-heavy game in two languages. A canvas board would cost accessibility, i18n and testability without adding much.
- three.js is worth adding (lazily) only if the owner later wants a 3D die or an Exhibition turntable.
- WebGL receives only public state. If WebGL is unavailable or the context is lost, the game falls back to the current SVG tinting.
