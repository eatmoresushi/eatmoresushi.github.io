## Important implementation note

The absence of a current central-board raster is intentional. The online board should be rendered from V0.4 structured data, which is safer than giving Codex an attractive but stale image.

For multi-ceramic Orders, matching is order-independent: selected ceramics can be assigned to requirement slots in any valid permutation.
