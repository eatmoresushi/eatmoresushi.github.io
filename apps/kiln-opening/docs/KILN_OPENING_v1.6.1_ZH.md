## 相对v1.2.7的改动

版本号为v1.61（工作名v1.3已被更早的一版草稿占用）。本草稿采纳全部已定改动，并删去所有涉及陶车坊、釉饰坊、窑坊、起始技艺、师傅超放规则、窑坊调位、“已施釉未装窑”状态以及旧委托阶段的文字。

1. **坊内地点。**每块窑口板上有两个在你自己作坊中进行的行动：制坯饰纹与施釉装窑，各2个工位，开局时只有1个可用。坊内行动以动作命名；中央地点以所去之处命名：泥柴场、瓷牙行、陶工行（沿用原名）、漕运码头（原杂作行）与州衙（原朝廷赞助）。
2. **制坯时饰纹，装窑时施釉。**制坯饰纹行动制坯并饰纹；施釉装窑行动施釉并装窑。不存在“已施釉而未装窑”的状态。
3. **火标。**施釉装窑行动的师傅将该玩家的火标暗置于其1件器物上；基础火候定后，按起始玩家顺序，将其翻为+1或−1，或收回。
4. **取消师傅超放。**所有容量均为绝对上限。
5. **无起始技艺；至多3项技艺，每门类至多1项；**共18张，每门类6张。坯作技艺添设制坯饰纹第二工位，釉作技艺添设施釉装窑第二工位；火作技艺不添设任何工位。
6. **委托。**只能完成在手委托，按派工阶段的回合顺序进行。被承接的榜上委托，须待承接者回合结束后才补上。师傅的一次承接可改为看三取一；色样簿现为提高委托上限的技艺。
7. **御烧优先**为1件坯施釉入窑。**御窑**由御匠代烧：2 + 窑火修正 + 装窑时选定的修正，不受控火影响。
8. **州衙（原朝廷赞助）**为限容地点，工位数1／1／2（2人／3人／4人），声望0–2时可用；师傅付3铜钱。御赐为1泥、1柴和1铜钱（3铜钱选项已取消），因此花钱买下第1格是实在的开销，而非原数返还。
9. **共窑**每名玩家2个窑位：4个（2-1-1）、6个（2-2-2）、8个（3-3-2）。
10. **哥窑**重做：开片纹饰由画花取代，哥窑改为每轮定品后令1件良品开片（其品质变为上品，并保留开片标，完成委托时可作任一纹饰）。
11. **火照**于基础火候定后、翻火标前结算（附录B）。
12. **窑火牌堆：**弃牌堆为公开信息；牌堆用尽时才重洗。
13. **委托分值：**O16为9分，O21为9分，O31为12分，O32为15分，O33为14分，O40为15分。
14. **纹饰一律2铜钱**（素面原为1铜钱）。师傅的制坯饰纹加成改为**制2件时1项纹饰−1铜钱**（原为泥总费−1）。饰坯匣改为少付1铜钱，而非减至0。定窑额外坯的费用为1泥和1铜钱。S10为4分。
15. **窑骰。**每轮开工时，掷一枚点数为1、1、2、2、3、3的骰子；结果即该轮基础火候的起点（原恒为2）。控火、0–5限定、窑火牌及其后一切均不变。御匠代烧的御窑以同一点数取代2。
16. **参与控火**须在共窑中有器物。由于御窑不受控火影响，其拥有者不能再仅凭御窑器物参与共窑控火（堵住第7条带来的无代价捣乱漏洞）。
17. **为“只能完成在手委托”留出余量。**每人开局持2张起始委托和1张主委托（原为1张和1张），委托上限为4张（有色样簿5张；原为3／4张）。承接张数仍为学徒1张／师傅2张。
18. **声望轨仍为可选。**声望轨上不派工人。州衙（原朝廷赞助）自声望0起开放（取消声望1的门槛），御赐为1泥、1柴和1铜钱；两者合起来以更少的文字解决第1格的返还问题，并让铜钱充裕的玩家可花钱登上声望轨，作为铜钱的去处。御烧优先保持草案原样；O17–O20保持牌面原样。
19. **画花取代开片**成为第4种纹饰（2铜钱）。开片如今只由哥窑在窑中产生，以标记表示。卡面改字：S13、O13、O17、O23、O39、O40、O46；饰坯匣文字为刻花、印花或画花。

## 游戏概述

在《开窑》中，每位玩家主持一座窑场作坊，取法宋代五种著名窑口传承之一。你的师傅与学徒采集泥柴、制坯、饰纹、在入窑时施釉，争接委托、竞习技艺，并共用一座窑——这一窑最终的烧成，受每一座参与作坊的影响。

**派工决定你的作坊备下什么；共窑烧成决定所备之物成为什么。**本次烧成中的所有器物共用同一基础火候与同一张窑火牌，因此你烧出什么，部分取决于其他人决定怎样烧火。

游戏恰好进行**5轮**。

## 游戏准备

1. 将中央行动板与共窑板放在桌子中央。共窑板：**4人**使用全部8个窑位（高温区3、中温区3、低温区2）；**3人**使用6个窑位，盖住1个高温区与1个中温区窑位（2-2-2）；**2人**使用4个窑位，盖住1个高温区、2个中温区与1个低温区窑位（2-1-1）。2人与3人游戏另盖住州衙第二工位。
2. 分别洗混**16张起始委托牌堆**与**48张主委托牌堆**。发给每位玩家**2张起始委托和1张主委托**。这3张委托构成该玩家开局的委托手牌，**须保密**。
3. 将未发出的起始委托全部放回盒中。将剩余主委托牌堆重新洗混，然后从左至右正面朝上翻开**6张主委托**。
4. 将18张技艺牌按坯作、釉作、火作分成3叠，每叠6张。各门类分别洗混，每门类正面朝上翻开**2张**。
5. 洗混12张窑火牌，面朝下放置，旁边为正面朝上的弃牌堆。将窑骰放在基础火候轨旁。
6. 将泥、柴、铜钱与器型卡放在众人方便取用之处。器型卡按器型分开。
7. 将**4块御窑板块**放在御府声望轨旁。
8. 每位玩家选择一种颜色，拿取1名师傅、3名学徒、1个火标、1个声望标、2个第二工位盖片，以及压火、守火、添柴各1张。将该颜色的**御烧优先标**放在声望轨第**3**格。
9. 随机决定起始玩家。按回合顺序的逆序，每位玩家选择1块可选的窑口板，用第二工位盖片盖住其制坯饰纹与施釉装窑的第二工位。
10. 每位玩家将**1名师傅 + 3名学徒**作为可派工人。
11. 每位玩家的御窑区保持空置，直到经御府声望获得御窑。
12. 每位玩家获得**2泥、2柴和3铜钱**。
13. 将所有声望标放在第**0**格，轮次标放在第**1**轮。

## 第1阶段——开工

每轮先**掷窑骰**，将基础火候标放在所得点数上（1、2或3）。本轮基础火候即以此为起点；之后由控火从这里调整。然后，在第2–5轮：

1. 将**最左2张**主委托弃入主委托弃牌堆。
2. 将余下**4张主委托**左移。
3. 翻开**2张新主委托**，从左至右填满两个空位，使委托榜恢复为**6张**。

然后重置所有标明**每轮一次**的能力，由起始玩家开始派工阶段。

## 第2阶段——派工阶段

从起始玩家开始，按顺时针方向，每位玩家须派**1名可派工人**至一个合法工位，并立即结算其行动。如此轮流，直到**每位玩家都已派出全部工人**，然后进入烧窑阶段。

每位玩家每轮有**1名师傅和3名学徒**可派。每名工人每轮派出一次，因此每位玩家全局共派工**20次，其中师傅5次**。

- 工人可派至某地点任一**空**工位；该地点其他工位上已有的工人，无论是你的还是他人的，都不影响。**容量是绝对的：**某地点的工位全部已占时，任何工人（包括师傅）都不能派往该地点。
- 师傅遵守与学徒相同的派工规则，并获得所在地点的师傅效果。
- 你须能执行该地点**至少1次主行动**，方可派工。“至多2”即**1或2，不能为0**。可选的额外收益仍可放弃。
- **派工阶段不得停派。**漕运码头无容量、无费用，可派工人永远可以派往该处。
- **坊内地点**位于你自己的窑口板上。每个坊内工位**每轮一次**。尚未添设的第二工位不可使用。

| **师傅** | 为你的1或**2**件坯施釉并装窑。然后将你的**火标暗置**于你在共窑或御窑中的1件器物上。师傅留在此工位。 |

- **装窑**：放入共窑一个空的启用窑位；若你已有御窑且其为空，**本次行动所装器物中可有1件**改放入御窑。
- 须至少有1件坯，并有空的启用窑位或你自己空置的御窑，方可派工。
- 停用窑位不算空位，也不可使用。御窑每次烧成容纳1件。
- 火标于烧窑阶段结算。每件器物至多1个火标。

### 瓷牙行

每次承接，任选其一：

- 承接委托榜上**1张主委托**，收入手中；其榜位**留空至你回合结束**，再将右侧委托左移并翻牌补至6张；或
- 盲接：**不看牌面，将主委托牌堆顶1张**直接收入手中，委托榜不动。

| 工人 | 效果 |
| --- | --- |
| 学徒 | 承接**1张主委托**，然后获得1泥、1柴或1铜钱。 |
| **师傅** | 承接**1或2张主委托**，逐次结算。其中1次可改为：查看主委托牌堆顶3张，承接1张，其余弃置。**每承接1张后，获得1泥、1柴或1铜钱。** |

- 师傅至少须承接1张，可在第1张后停止；因回合结束前不补榜，第二次只能从仍在榜上的委托中选。
- 一轮中无委托上限。收工时，自选弃置委托，直至不超过你的委托上限**4**张（有色样簿则5张）。起始委托与承接的主委托都计入。
- **在手委托保密。**各人手中委托张数公开。

### 陶工行

| 工人 | 效果 |
| --- | --- |
| 学徒 | 支付牌面铜钱费用，习得**1张公开技艺**。 |
| **师傅** | 选择1个门类，查看该牌堆顶2张**（不足则看余数）**。然后习得任一门类的1张公开技艺或所看的1张，少付1铜钱，最低为0。未取的所看技艺置于该牌堆底。 |

- 取走1张技艺牌后，尽可能将该门类补至2张。
- 每人至多**3项技艺，每门类至多1项**。
- **添设工位。**习得坯作技艺即添设制坯饰纹第二工位（移去其上的第二工位盖片）；习得釉作技艺即添设施釉装窑第二工位（同上）；火作技艺不添设工位。新添设的工位本轮稍后即可使用。
- 派学徒须付得起1张你尚无其门类的公开技艺；派师傅须在减免后付得起这样一张。
- 新习得的技艺，时机允许即可于本轮使用。**“习得时”**效果立即结算。

## 第3阶段——烧窑阶段

共窑与所有御窑皆空时，**本轮不烧窑，不翻窑火牌**。

| 步骤 | 内容 | 得出 |
| --- | --- | --- |
| 1. 控火 | 参与控火的玩家暗选压火、守火或添柴，以及柴簿加柴（如有），然后亮牌付柴。从窑骰点数起算，最终结果限定在0–5。 | **基础火候** |
| 2. 火照 | 按起始玩家顺序，拥有火照者可查看窑火牌堆顶1张，并可将其置于牌堆底。 | — |
| 3. 翻火标 | 按起始玩家顺序，器物上有暗置火标的玩家将其翻为+1或−1，或收回。窑工于此时放置窑工标。 | — |
| 4. 翻窑火 | 翻开窑火牌堆顶1张，加上其修正。 | **全窑火候** |
| 5. 窑位 | 共窑器物：全窑火候 + 温区修正（高温区+1／中温区0／低温区−1，或窑具修正）+ 火标。御窑器物：窑骰点数 + 窑火修正 + 装窑时选定的御窑修正 + 火标。 | **实际火候** |
| 6. 比对 | 结算适用能力后，比对实际火候与适烧火候。 | **品质** |

- **基础火候与全窑火候属于整次烧成，实际火候属于单件器物。**
- 基础火候限定在0–5。全窑火候与实际火候不设上下限。

### 控火牌

每位玩家有相同的3张控火牌：

| 控火 | 柴 | 火候 |
| --- | --- | --- |
| 压火 | 1 | −1 |
| 守火 | 0 | 0 |
| 添柴 | 1 | +1 |

只有**在共窑中至少有1件器物的玩家才参与控火。御窑中的器物由御匠代烧，其主人不因此对共窑之火有发言权**。守火永远付得起。烧成后，将所有控火牌还给各自主人。

**基础火候 = 窑骰点数 + 最终控火修正之和，限定在0–5。**以窑骰点数为2为例：守火 + 守火 + 守火 → 2。添柴 + 守火 + 守火 → 3。压火 + 守火 + 守火 → 1。添柴 + 压火 + 守火 → 2；两位玩家仍须各付其柴。窑骰点数为3时：守火 + 守火 + 守火 → 3；压火 + 守火 + 守火 → 2；添柴 + 添柴 + 守火 → 5。

### 火标

- 每位玩家有1个火标，两面为+1与−1。施釉装窑行动的师傅将其**暗置**于该玩家在共窑或御窑中的1件器物上。
- 基础火候定后，按起始玩家顺序，每位有暗置火标的玩家**将其翻为+1或−1，或收回**。
- 火标将其数值计入该器物的实际火候。它不是温区修正：可与支烧窑具叠加，复烧重算时火标留在原处。
- 一件器物至多带1个火标。器物离开窑时，收回火标。

### 品质表

| 火候差 | 品质 | 委托资格 |
| --- | --- | --- |
| 0 | **臻品** | 满足任何最低品质要求。 |
| 1 | **上品** | 满足“上品以上”与“良品以上”。 |
| 2 | **良品** | 仅满足“良品以上”。 |
| 3或以上 | **瑕品** | 不能用于完成委托，不能陈列。 |

本次烧成的所有定品后能力结算完毕后，每位玩家可弃置**1件本次烧成中仍为瑕品的器物**，获得**2铜钱**。将其器型卡放回相应器型的供应堆。

### 御窑

首次到达**御府声望2**时，取1块御窑板块，放入你的御窑区。

- 御窑**每次烧成容纳1件**。
- 施釉装窑行动中，该行动所装器物中可有1件改放入你空置的御窑，而不放入共窑。御烧优先也可将器物装入御窑。任何技艺效果都不能装入御窑。
- 御窑器物**由御匠代烧。装入时选定御窑修正−1、0或+1并记录。实际火候 = 窑骰点数 + 窑火修正 + 御窑修正 + 火标（如有），不论控火如何；仍于共同的烧窑阶段烧成**。
- 对你的技艺与能力而言，它算作本次烧成中的器物，但不使你成为控火者：只有共窑中的器物才会。它不占共窑窑位。
- 烧成后，其器物照常定品，移入主人的成器区。

到达**御府声望3**时，从声望轨第3格取回你颜色的御烧优先标。**每局一次，在你的工人行动之前或之后，你可以交出此标，为你的1件坯施釉并装入你空置的御窑。**这是令牌效果，不是施釉装窑行动。

## 第4阶段——交货阶段

从**起始玩家**起顺时针，每位玩家可以**逐张完成任意张在手委托**。只能完成你手中的委托。**委托榜上的主委托不能完成**；它们在派工阶段于瓷牙行承接。交货阶段中委托榜不变。

完成步骤见下文**完成委托**。

## 第5阶段——收工

1. 所有工人归还其主人。收回仍留在共窑上的窑位签。
2. 自选弃置在手委托，直至不超过委托上限**4**张（有色样簿则5张）。弃置的起始委托放回盒中；弃置的主委托放入主委托弃牌堆。
3. 若这是第5轮，进入终局计分。否则，将起始玩家标顺时针传递，并推进轮次标。

## 器物制作

### 制作步骤

1. 获得泥和柴（泥柴场）。
2. 制1件坯并选定其纹饰（制坯饰纹）。
3. 为其施釉，并装入共窑，或装入你的御窑（若有）（施釉装窑）。
4. 结算共同的烧窑阶段。
5. 用成器完成1张在手委托，或留待终局陈列。

技艺可压缩这些步骤。

## 作坊发展

每位玩家作坊的长期引擎由以下构成：

> **1项窑口传承 + 至多3项技艺，每门类1项 + 至多2个添设的第二工位**

### 技艺效果与工人行动

**技艺效果不是工人行动。**若某项技艺让你执行工人行动的一部分，例如制坯、施釉或装窑，这**不**算执行了该工人行动，也不触发需要该行动的效果，除非文字写明。御烧优先同样是令牌效果。

### 技艺规则

- 坯作、釉作、火作技艺恰好各有6张。
- 每位玩家至多拥有3项技艺，每门类至多1项。
- 习得坯作技艺即添设制坯饰纹第二工位；习得釉作技艺即添设施釉装窑第二工位；火作技艺不添设工位。
- 依各技艺牌所印的时机与使用次数结算。
- 若你拥有多项时机相同的能力，由你自定结算顺序。若多名玩家在同一时机都有能力，按起始玩家顺序依次结算各玩家；每位玩家自定己方能力的顺序。
- 每项技艺**于习得时立即得1分**；终局不再另计。

全部18张技艺牌见附录B。

## 委托与御府声望

### 主委托牌堆与委托榜

游戏中只有一个**48张的主委托牌堆**和一个**6张的委托榜**。另有单独的16张起始委托牌堆，只在游戏准备时使用。

委托榜按新旧排列：**最左一张最旧**，**最右一张最新**。

榜上的主委托只有在被**承接**（瓷牙行、色样簿）或**于开工时弃置**时，才离开委托榜。某张被承接后，其榜位留空至承接者回合结束；然后将其右侧每张委托左移一位，并翻开主委托补入最右侧的空位，使委托榜恢复为6张。若一个回合中从榜上取走不止一张委托，在该回合结束后补榜，而不是在两次承接之间补榜。

委托可奖励**分、铜钱与0–3个御令**。商贾委托通常要求较宽松，铜钱较多。御令委托通常要求较具体，铜钱较少，并能提升御府声望。

### 承接委托

派工阶段在瓷牙行承接主委托。每次承接，取委托榜上1张委托，或不看牌面取主委托牌堆顶1张；师傅的其中1次承接可改为查看主委托牌堆顶3张，承接其中1张。习得**色样簿**可不经瓷牙行行动，立即从牌堆顶3张中承接1张，并使你的委托上限升为5张；见附录B。

在手委托：

- 在你的**秘密委托手牌**中，不受其他玩家影响；
- 收工时计入你的委托上限；
- 可在之后任一交货阶段完成，或经漕船完成；
- 完全按卡面所印计分。

### 完成委托

在交货阶段你的回合中，每完成1张委托：

1. 选择1张在手委托并**亮出**。
2. 选出所需的未交付成器。
3. 确认器型、釉、纹饰、相互关系与最低品质等全部要求均已满足。
4. 将所用器物压在已完成的委托下。
5. 记录所印分数。
6. 获得所印铜钱。
7. **逐个**结算御令。每个御令使御府声望推进1格，直至声望4。声望已达4后，此后每个御令**立即得1分**。途经的每一格声望奖励都须结算。
8. 将已完成的委托正面朝上放入你的计分区。

一件器物只能用于一张已完成的委托。

#### 多件委托的要求读法

除非卡面**明确印出特定配对**，各项要求**彼此独立**。若委托写“**碗 + 笔洗；白釉、月白釉各1件；素面、印花各1件**”，你须恰好使用1件碗和1件笔洗、白釉和月白釉各恰好1件、素面和印花各恰好1件，在两种器型之间任意分配。若卡面意在固定配对，会直接写出配对，例如“**碗：白釉 + 素面；笔洗：月白釉 + 印花**”。

### 御府声望轨

御府声望可由**已完成委托上的御令**或**在州衙付费**推进。州衙不能使你推进至声望4。

| 声望 | 名称 | 首次到达时获得 |
| --- | --- | --- |
| 0 | 民间作坊 | — |
| 1（1个御令） | 御赐 | 获得**1泥、1柴和1铜钱**。 |
| 2（2个御令） | 赐御窑 | **获得御窑板块，放入你的御窑区：私人单格窑，由御匠代烧，实际火候 = 窑骰点数 + 窑火修正 + 装窑时自选的御窑修正 + 火标，不受控火影响。** |
| 3（3个御令） | 御烧优先 | 从声望轨第3格取回你颜色的**御烧优先标**。每局一次，在你的工人行动之前或之后，你可以交出此标，为你的1件坯施釉并装入你空置的御窑。 |
| 4（4个御令） | 御前召见 | 获得**6分**。 |
| 此后每个御令 |  | +1分 |

- 声望达4后，**你每再获得1个御令，立即得1分**。
- 御令须**逐个**结算。一张多御令委托可连跨数格声望奖励，到达声望4，再以同一张委托上余下的御令得分。
- 御赐、御窑、御烧优先标与御前召见各只获得一次。

### 终局陈列

终局时，陈列你**任意数量**的良品以上未交付成器。

| 品质 | 每件得分 |
| --- | --- |
| 良品 | **2** |
| 上品 | **3** |
| 臻品 | **5** |

然后每项多样奖励各计一次：陈列中至少有**3种不同器型**，**+3分**（器备三形）；至少有**3种不同釉**，**+3分**（釉备三色）。瑕品不能陈列。

## 窑口传承能力

窑口板上印的是短提示文字；本节规则给出完整效果。

### 汝窑 · 天青无瑕

每轮一次，当你完成委托时，若所交付器物中有1件为臻品、青釉、素面，获得4分。委托本身不必要求臻品、青釉或素面；只看实际交付器物的属性。

### 官窑 · 内府恩眷

每轮一次，当你完成一张印有至少1个御令的委托时，获得2铜钱和1分。

### 哥窑 · 金丝铁线

每轮一次，定品后，选择你本次烧成中1件当时为良品的器物：其开片，品质变为上品。在其上放置开片标；该器物保留此标。

完成委托时，你的每件开片器可视为具有任意一种纹饰，以满足该委托的纹饰要求；其原纹饰不变。开片器永不是臻品，不能满足臻品要求。

### 定窑 · 范制成器

每轮一次，在结算制坯饰纹行动时，你制成1件碗、盘或笔洗后，可支付1泥和1铜钱，再制1件同器型的坯，并任选1种纹饰；该纹饰费用即为这1铜钱。此额外坯不计入该行动的件数上限，也不是师傅纹饰减免所指的“2件”之一；对提及“该行动所制坯”的效果，视为该行动所制。

### 钧窑 · 窑变天成

每轮一次，实际火候算出后、定品前，你可以支付1柴，将你1件器物的实际火候调整+1或−1。

### 能力时机

- 若多名玩家在同一时机结算能力，从起始玩家起顺时针依次结算。
- 钧窑于实际火候算出后（火标已计入）、定品前结算。
- 哥窑开片是定品后效果；哥窑玩家自定其在己方各项定品后效果中的结算顺序（可在匣钵护烧之后作用于同一器物）。
- 汝窑与官窑于完成委托时触发，无论是在交货阶段还是经漕船完成；开片器的任意纹饰于完成委托时声明。
- 定窑于其制坯饰纹行动中触发。

## 终局与计分

第5轮收工后游戏结束。计分：

1. 游戏中记录的全部分数，包括委托、窑口传承能力、**每项技艺1分**（习得时已计）、**御前召见**，以及声望达4后所得御令的分数；
2. 技艺不再另计：每项已于习得时计**1分**；
3. 终局陈列；
4. **余钱每3铜钱1分**，至多**5分**。

得分最高者获胜。

**平局判定：**①御府声望更高。②已完成委托上印有的御令总数更多。③已交付或陈列的臻品更多。④仍平则共享胜利。

## 通则

- **资源无限：**泥、柴与铜钱的公共供应无限。若配件用尽，用合适的代用物，如备用标记或计数物，或在纸上记下多出的数量。每种代用物所代表的资源种类与数量须让所有玩家一目了然。
- 泥、柴与铜钱从公共供应获得；所花费的泥、柴与铜钱全部退回公共供应。
- **资源是公开信息。**每位玩家的泥、柴与铜钱总数须让所有玩家清楚可见，并在被询问时如实告知。控火选择与柴簿加柴在亮牌前保密。为控火所押的柴，在支付前仍计入该玩家的总数。
- **不得交易：**玩家之间不得交易泥、柴、铜钱、委托、技艺或器物。
- **协商：**玩家可以讨论各自打算的控火与火标，并可作出承诺。这些承诺不具约束力。玩家须如实披露公开信息，且不得在玩家之间转移资源或其他游戏配件。
- **在手委托是秘密信息。**每位玩家手中委托的张数公开。
- **所有未交付器物都是公开信息**，包括坯、入窑器物与成器，以及其上记录的全部属性。
- 坯、入窑器物与成器跨轮保留，并保持所记录的全部属性，直至某条规则明确改变、交付或弃置它们。
- 未完成的委托与未用的器物在终局不扣分。
- 需要抽牌时若主委托牌堆已空，将其弃牌堆洗混，组成新的牌堆。
- **窑火弃牌堆是公开信息。**游戏中窑火牌堆不重洗；只有在需要翻牌而牌堆已空时，才将其弃牌堆洗混，组成新的牌堆。
- 若某门类的公开技艺无法补至2张，则留出空位。

- **折扣：师傅纹饰减免、饰坯匣、定窑1铜钱额外坯是三项各自独立的减免。前两项可作用于同一纹饰（刻花0铜钱）；定窑额外坯两者皆不适用。大陶车只减泥；定窑额外坯不是瓶或香炉。**
- **高徒**在瓷牙行：该学徒获得师傅的2次承接、其中1次可看三取一，以及每次承接后的1份资源。
- **哥窑开片**是定品后效果，可在匣钵护烧之后作用于同一器物（瑕品→良品→上品，每轮一次）。开片器永不为臻品，不能满足任何臻品要求（含画花臻品委托）。

## 附录D——完整烧窑流程

若共窑与所有御窑中都没有器物，**本轮不烧窑，也不翻窑火牌**。

1. **暗选控火。**在共窑中至少有1件器物的每位玩家，暗选压火、守火或添柴，且须付得起其柴费。有柴簿者可随之暗附柴簿加柴。
2. **亮牌付柴。**同时亮出所有控火牌与暗附的柴，然后支付全部费用。
3. **定基础火候。**以窑骰点数为起点，加上所有最终控火修正，再限定在0–5。
4. **火照。**按起始玩家顺序，每位拥有火照、且在本次烧成中有器物的玩家，可支付1柴查看窑火牌堆顶1张，并可将其置于牌堆底。
5. **翻火标。**按起始玩家顺序，每位在器物上有暗置火标的玩家，将其翻为**+1或−1**，或将其收回。拥有窑工者在此步骤放置窑工标。
6. **翻窑火。**翻开窑火牌堆顶1张，将其修正加到基础火候上。所得为全窑火候，不设上下限。
7. **算实际火候。**共窑器物：全窑火候 + 温区修正（或窑具修正）+ 火标。御窑器物：窑骰点数 + 窑火修正 + 装窑时自选的御窑修正 + 火标。
8. **调火。**按起始玩家顺序，结算钧窑及其他于实际火候算出后、定品前发动的能力。
9. **定品。**以最终实际火候与适烧火候比较。
10. **定品后结算。**按起始玩家顺序，结算匣钵护烧、复烧、哥窑开片及类似效果。若你在此时机有多项能力，由你自定其先后顺序。
11. **折卖瑕品（可选）。**每位玩家可弃置1件本次烧成中仍为瑕品的器物，获得2铜钱。将其器型卡放回相应器型的供应堆。
12. **开窑取器。**将其余所有成器移入各自主人的成器区。清空共窑与御窑的所有窑位。将火标、窑工标与支烧窑具归还各自主人，窑火牌正面朝上弃置，并收回所有控火牌。

| --- | --- |

| 基础火候定后、翻火标前 | 4 |
| 火标步骤中 | 5 |
| 实际火候算出后、定品前 | 8 |

## 附录E——速查

### 一轮流程

1. **开工：**掷窑骰，定本轮基础火候起点（1、2或3）；第2–5轮弃置最左2张主委托，余4张左移，再翻2张新委托，补回**6张委托榜**；重置“每轮一次”能力。
2. **派工阶段：**自起始玩家起顺时针；每位玩家每回合须派1名工人。不得停派；所有玩家的工人全部派出后结束。
3. **烧窑阶段：**控火 → 基础火候 → 火照 → 翻火标 → 翻窑火 → 实际火候 → 调火 → 定品。
4. **交货阶段：**自起始玩家起顺时针；每位玩家可逐张完成任意张数的在手委托。榜上委托不能完成。
5. **收工：**收回工人与标记；削减委托至上限（4张；有色样簿5张）；若游戏继续，传起始玩家标并推进轮次。

### 行动一览

**容量：**泥柴场、瓷牙行与陶工行在2／3／4人局中各有2／3／4个工位。漕运码头不限人数。州衙有1／1／2个工位，声望0–2时可用。制坯饰纹与施釉装窑在你的窑口板上：各1个工位，添设后各增1个。所有容量均为绝对上限。

### 御府声望

- **1个御令——御赐：**获得**1泥、1柴和1铜钱**。
- **2个御令——赐御窑：**获得你的**御窑板块**（御匠代烧：窑骰点数 + 窑火修正 + 自选的御窑修正，不受控火影响）。
- **3个御令——御烧优先：**取回你颜色的御烧优先标。每局一次，在你的工人行动之前或之后，你可以交出此标，为你的**1件坯**施釉并装入你空置的御窑。
- **4个御令——御前召见：**获得**6分**。此后每获得1个御令，**立即得1分**。
- 已完成委托上的御令与州衙均可推进御府声望；州衙不能推进至声望4。

### 技艺规则

技艺效果**不是工人行动**。除非文字写明，它不计为一次地点行动，也不触发需要该工人行动的效果。派工须至少执行**1次该地点的主行动**；“至多2”即**1或2，不能为0**。

### 烧窑

**基础火候以窑骰点数为起点，窑骰于每轮开工时掷出（点数1、1、2、2、3、3）。**压火1柴／−1 · 守火0柴／0 · 添柴1柴／+1。

| 火候差 | 品质 |
| --- | --- |
| 0 | 臻品 |
| 1 | 上品 |
| 2 | 良品 |
| 3或以上 | 瑕品 |

- **火标：**基础火候定后，按起始玩家顺序翻为+1或−1；计入该器物的实际火候。
- **哥窑：**每轮一次，定品后：己方本窑1件良品开片升上品；完成委托时，开片器可作任一纹饰。
- 定品后结算之后，每位玩家可弃置**1件本次烧成中仍为瑕品的器物**，获得**2铜钱**。

- 已完成委托的分数。
